# Contributing

For a proposed addition or correction, provide the exact title, author list, formal publication year, venue/track, primary URL or DOI, and a short explanation of relevance to text hallucination. Distinguish conference main tracks, Findings, journals, workshops and preprints. Prefer a published version over a duplicate preprint.

Assign one primary category and at least one subcategory, while retaining secondary roles in a note when needed. Do not infer the mechanism or a state-of-the-art claim from a title alone. Preserve the screening level and state whether the full text or code was checked. Do not copy full paper PDFs or figures into this repository without an appropriate right to redistribute them.

Updates to data should also update counts, the reading map and any affected tables. Run `python scripts/validate_resources.py`. Changes to diagrams should preserve editable SVG and regenerate PDF/PNG previews from the source script.

No automated update schedule is currently configured.
